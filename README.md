# Summary AI - Documentation publique

> Bot Discord d'IA pour résumer les conversations d'un serveur Discord.

Ce dépôt est le dépôt public officiel de documentation pour **Summary AI**.
Il contient uniquement les documents publics du bot :

- les manuels d'utilisation ;
- la politique de confidentialité ;
- les conditions générales d'utilisation.

Le code source du bot, sa configuration, ses secrets, sa base de données et ses outils internes ne sont pas publiés dans ce dépôt.

La documentation est disponible en **français** et en **anglais**. En cas de divergence entre les traductions, la version française fait foi.

### À propos de Summary AI

Summary AI permet de générer des résumés de conversations Discord via une commande slash. Le bot utilise des crédits, respecte les préférences de confidentialité des membres et applique une anonymisation par défaut dans les résumés.

Pour comprendre le fonctionnement complet du bot, consultez le [manuel utilisateur français](docs/manuels/manual-fr.md).

### Confidentialité et droits RGPD
